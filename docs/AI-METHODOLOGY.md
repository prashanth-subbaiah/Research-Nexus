# Search and research connections

The published showcase uses transparent browser-side keyword search and specialization rules. It does not run a generative model or sentence-embedding service.

Search normalizes words from the title, subject, description, and skills, then ranks topics by matched query terms. Subject and experience filters narrow the result set. This is a discovery aid, not a validated semantic relevance benchmark.

Faculty connections map the listed specialization to related catalog subjects. Examples: network security connects to phishing classification; cloud computing connects to workload traces; image processing, computer vision, and deep learning connect to visual inspection and leaf-image classification. Broad IT/CSE entries receive general computing connections, labeled accordingly. The UI states that suggestions are not confirmed supervision or research involvement.

The planner presents a fixed research-preparation checklist, editable notes, and an export. It does not invent sources, claim to have run experiments, or manufacture papers and results.
